# 📈 ระบบสแกนหุ้นและคริปโต แจ้งเตือนผ่าน LINE อัตโนมัติ

ระบบค้นหาหุ้นสหรัฐฯ (US Stocks), หุ้นไทย (SET) และคริปโตเคอร์เรนซี (Crypto) ที่มีสัญญาณเทคนิคอลโดดเด่น และส่งข้อความสรุปเข้า LINE Official Account ผ่าน Broadcast API

---

## 📁 โครงสร้างไฟล์
- `config.py`: ตั้งค่า Token และรายชื่อหุ้น/เหรียญคริปโตที่ต้องการสแกน
- `scanner.py`: คำนวณอินดิเคเตอร์ (EMA, RSI, MACD, Volume Spike, Breakout)
- `line_notifier.py`: จัดรูปแบบรายงานและส่งข้อความ Broadcast เข้า LINE
- `main.py`: ไฟล์หลักสำหรับเริ่มสแกนและส่งผลลัพธ์
- `index.html`, `style.css`, `app.js`: หน้าเว็บ Stock & Crypto Screener
- `build_market_data.py`: สร้าง snapshot ราคาหุ้นและสัญญาณให้หน้าเว็บ
- `run_scanner.bat`: ดับเบิ้ลคลิกเพื่อรันบน Windows ได้ทันที

## 🌐 หน้าเว็บ MarketScope

### รายการสินทรัพย์สหรัฐ 200 ticker
`US_STOCKS` ขยายเป็น 200 ticker ไม่ซ้ำ รวมรายชื่อเดิมและ ETF เดิม 10 รายการ เพิ่มหุ้นซอฟต์แวร์ ชิป ธนาคาร ประกัน สุขภาพ อุตสาหกรรม ผู้บริโภค สาธารณูปโภค อสังหาริมทรัพย์ พลังงาน และวัสดุ เป็น curated universe ไม่ใช่การจัดอันดับ Market Cap หุ้นที่เพิ่มใช้ pipeline ราคาและสัญญาณเดียวกัน (RS, Liquidity, Strong Close ฯลฯ) หน้าเว็บแสดงจำนวนที่โหลดได้จริงในแท็บหุ้นสหรัฐ และแบ่งหน้าละ 25 รายการ

### Relative Strength / Liquidity / Strong Close
- **RS 20/60D:** ผลตอบแทนสินทรัพย์ − ผลตอบแทน benchmark บนวันเริ่มและวันปิดเดียวกัน หน่วย **จุดเปอร์เซ็นต์ (pp)** ไม่ใช่ RSI หุ้นไทยเทียบ SET (`^SET.BK`), สหรัฐเทียบ S&P 500 (`^GSPC`), คริปโทเทียบ BTC ในหน่วย USD หรือ USDT ตามประวัติที่ใช้ เงื่อนไข RS เหนือตลาดต้อง >0 ทั้ง 20 และ 60 แท่งปิด กำหนดช่วงและ RS ขั้นต่ำเองได้
- ต้องมีข้อมูลครบทุก session ในหน้าต่าง benchmark โดยไม่ forward-fill และไม่ใช้วันหลังแท่งสินทรัพย์ ข้อมูลไม่ครบแสดง “—” ไม่แทนด้วย 0; BTC เทียบตัวเองจึง RS=0 หุ้นใช้ปิดปรับสิทธิเทียบ price index; SET ที่ประวัติรายวันไม่ครบใช้แท่งชั่วโมงของ SET จริงมารวมเป็นค่าปิด session พร้อมระบุ source ไม่ใช้ ETF แทน
- **Liquidity:** เฉลี่ยมูลค่าซื้อขาย 20 แท่งปิด เริ่มต้นไทย ≥20M THB, US ≥10M USD, Crypto ≥5M USD/USDT หุ้นประมาณจากปิดปรับสิทธิ × จำนวนซื้อขาย; Yahoo crypto ใช้ Volume USD ที่รายงานโดยตรง ไม่คูณราคาซ้ำ; Binance ใช้ QuoteVolume USDT จากแท่งเทียน ค่าเกณฑ์เงินในเว็บเป็น “ล้าน” ในหน่วยรายตัว ไม่ได้แปลงอัตราแลกเปลี่ยนข้ามตลาด เมื่อกรอกขั้นต่ำเองจะใช้ค่านั้นแทนเกณฑ์ checkbox Liquidity และแสดง badge ตามค่าที่กำหนด
- **Strong Close:** `(Close−Low)/(High−Low) ≥75%` และ Volume ≥1.5× ค่าเฉลี่ย 20 แท่งก่อนหน้า แท่ง High=Low หรือราคาปิดอยู่นอกกรอบไม่ถือว่าปิดแข็งแรง กำหนด % ปิดในแท่งขั้นต่ำเองได้
- Preset ใหม่: **Market Leaders · RS + Liquidity** และ **Breakout Quality · ปิดแข็งแรง** ใช้ร่วม AND/OR, watchlist และบันทึกตัวกรองได้ ตัวกรองใหม่ใช้เฉพาะแท่งปิดที่ไม่ล่าช้าและ snapshot อายุไม่เกิน 3 ชั่วโมง ตามเขตเวลาตลาด (วันหยุดอาจถูกระบุว่าล่าช้า)
- ตารางแสดง RS20/60, benchmark, มูลค่าเฉลี่ย20D พร้อมหน่วย และตำแหน่งปิดในแท่ง Strong Close เพิ่ม 10 คะแนน, RS เหนือตลาดเพิ่ม 10 คะแนน, Liquidity เป็นตัวกรองคุณภาพและไม่เพิ่มคะแนนทิศทาง

### โลโก้และภาพรวม SET Index
ใช้โลโก้ MarketScope จากภาพต้นฉบับที่ผู้ใช้ส่งมาในหน้า Screener และ CostPilot พร้อมไอคอนแท็บเบราว์เซอร์ ภาพรวม SET Index ดึงจาก Yahoo Finance ticker `^SET.BK` ผ่าน `build_indices.py` และเผยแพร่ใน `data/indices.json` ทุก 30 นาที เว็บโหลดพร้อมหุ้น/คริปโททุก 5 นาที แสดงค่าดัชนีเป็นจุด การเปลี่ยนแปลงจากปิดก่อนหน้า ราคาเปิด สูงสุด ต่ำสุด และกราฟจากแท่ง 15 นาทีจริง พร้อมเวลาอ้างอิงจากผู้ให้บริการ ข้อมูลอาจล่าช้า ไม่ใช่ feed real-time หรือข้อมูลตรงจาก SET หากโหลดไม่สำเร็จใช้ข้อมูลที่เผยแพร่/โหลดสำเร็จรอบก่อนพร้อมป้ายแจ้ง ไม่ใส่ตัวเลขหรือกราฟตัวอย่างแทน

### ภาพรวม S&P 500 และ Bitcoin
S&P 500 ใช้ ticker `^GSPC` จาก Yahoo Finance แสดงจุด/% เทียบปิดก่อนหน้า ราคาเปิด สูงสุด ต่ำสุด และกราฟวันตลาดล่าสุดตามเขตเวลานิวยอร์ก Bitcoin ใช้ราคา/% เปลี่ยนแปลง 24 ชม., Volume 24 ชม. (USD), Market Cap และอันดับจาก CoinPaprika; กราฟย้อนหลัง 24 ชม. และเปิด/สูงสุด/ต่ำสุดของวัน UTC ใช้แท่ง 15 นาที `BTC-USD` จาก Yahoo Finance แสดงแหล่งข้อมูลและเวลาราคา/กราฟแยกกัน RSI/ปิดวิเคราะห์มาจาก snapshot คริปโทที่ตรวจตัวตนแล้ว พร้อมวันแท่งปิดและหน่วย USD หรือ USDT ตามแหล่งจริง

หาก CoinPaprika ใช้ไม่ได้ Bitcoin สำรองราคาจาก Yahoo Finance โดยเปลี่ยนป้าย % เป็น “เทียบปิดก่อนหน้า (Yahoo)” หรือ “เทียบปิด UTC ก่อนหน้า” เมื่อมีแท่งปิด UTC ครบ ไม่แสดงว่าเป็น 24 ชม. กราฟวาดจากข้อมูลจริงเท่านั้น แต่ละการ์ดเก็บข้อมูลรอบก่อนเมื่อดึงใหม่ไม่สำเร็จ Bitcoin ในภาพรวมมี loader เดียว จึงไม่ถูกการโหลด Crypto Top 100 เขียนทับจนราคา/กราฟมาจากคนละรอบโดยไม่ระบุเวลา

GitHub Actions ตั้งรอบนาทีที่ 17 และ 47 ของทุกชั่วโมง (อาจเริ่มช้าตามคิว GitHub) หน้าเว็บตรวจ snapshot ใหม่ทุก 5 นาทีเมื่อเปิดแท็บและออนไลน์ ปิด/เปิดอัตโนมัติได้ และไม่มีการเรียกซ้อนระหว่างโหลด พักเมื่อแท็บถูกซ่อน แล้วตรวจเมื่อกลับมาและถึงรอบ ปุ่มรีเฟรชอ่าน snapshot ล่าสุด ไม่ได้สั่ง workflow ใหม่ Watchlist และตัวกรองยังอยู่หลังรีเฟรช; เมื่อโหลดไม่สำเร็จคงข้อมูลเดิมและแสดงสถานะ

เมนู “สถานะข้อมูล” เปิดแผงการอัปเดตข้อมูลแยกจากหน้า screener (บนมือถือเปิดจากปุ่มด้านบน) แสดงเวลาสร้างชุดข้อมูล เวลาตรวจบนเว็บ เวลาอ้างอิงราคา วันแท่งสัญญาณ จำนวนข้อมูลและรอบตามแผนถัดไป แยกหุ้นไทย หุ้นสหรัฐ และคริปโท ปิดแผงด้วยปุ่มปิดหรือ Escape โดยระบบรีเฟรชอัตโนมัติยังทำงาน สัญญาณหุ้นใช้แท่งปิดหลังเวลาไทย 17:15 / นิวยอร์ก 16:30 (เผื่อการเผยแพร่หลังปิด) วันหยุดอาจทำให้ราคายังคงเป็นวันก่อนหน้า LINE Watchlist ยังตรวจหลังปิดตลาดตามเวลาเดิม ไม่แจ้งทุกครั้งที่ราคาขยับ

### CostPilot · วางแผนต้นทุน
เปิดเมนู “CostPilot · วางแผนต้นทุน” หรือ https://benzsutthi.github.io/stock-crypto-scanner/average-cost.html แล้วกรอกต้นทุนเฉลี่ยเดิม จำนวนที่ถือ ราคาและจำนวนที่จะซื้อเพิ่ม รองรับหน่วยทศนิยมและค่าธรรมเนียมซื้อเพิ่ม ผลลัพธ์แสดงต้นทุนเฉลี่ยใหม่ จำนวนรวม เงินซื้อเพิ่ม และต้นทุนรวม โดยใช้สูตร `(ต้นทุนเดิม × จำนวนเดิม + ราคาซื้อเพิ่ม × จำนวนซื้อเพิ่ม + ค่าธรรมเนียม) ÷ จำนวนรวม` คำนวณทันทีในเบราว์เซอร์ ไม่ต้องใช้ข้อมูลตลาด

### ข้อมูลคริปโท
หน้าเว็บโหลด `data/crypto.json` จาก GitHub Pages โดยตรง จึงไม่ต้องเรียก API ต่างประเทศจากเครื่องผู้ใช้ อันดับ Market Cap และราคามาจาก CoinPaprika (สำรอง CoinGecko) และสัญญาณคำนวณจากแท่งปิดรายวันของ Yahoo Finance USD (สำรอง Binance market-data-only USDT) รอบอัปเดตทุก 30 นาที รวมวันเสาร์–อาทิตย์ แสดงจำนวนเหรียญที่วิเคราะห์ได้ เวลาอัปเดต และสถานะประวัติไม่พร้อม เหรียญที่ไม่มีแท่งครบ 50 วัน, แท่งล่าสุดไม่ใช่เมื่อวาน UTC, ticker ซ้ำ หรือยังไม่ยืนยันตัวตน จะไม่สร้างสัญญาณสมมติ หากผู้ให้บริการขัดข้องใช้ snapshot ที่เผยแพร่สำเร็จรอบก่อน หรือประวัติเดิมพร้อมป้ายเตือน และไม่ใช้ข้อมูลสำรองคัดกรองต้นรอบ

### ตัวกรองและ Watchlist
ดูหัวข้อการปรับปรุงต้นรอบและข้อมูลด้านล่างสำหรับฟีเจอร์ใหม่
- เลือกเงื่อนไขหลายข้อแบบ AND/OR และกำหนดช่วง RSI, Volume ratio, คะแนนขั้นต่ำ
- Preset: Breakout แข็งแรง, โมเมนตัมขาขึ้น, Oversold; กดบันทึกเพื่อจำตัวกรองในเบราว์เซอร์
- กดดาวเพื่อติดตามและเปิด “เฉพาะ Watchlist”; ตารางแบ่งหน้าละ 25 รายการ
- สัญญาณใช้แท่งรายวันที่ปิดแล้ว; วันราคาปิดแสดงรายตัวและแสดง “ข้อมูลเก่า” เมื่อเกิน 4 วันปฏิทิน (รวมวันหยุด)
- คะแนนหุ้นและคริปโทใช้หลักเดียวกัน: Breakout 35, RSI momentum 15, Oversold 10, Volume 20, MACD cross 20, EMA trend 10; RSI ≥70 เป็นคำเตือน ไม่มีคะแนนเพิ่ม

### แจ้ง LINE เฉพาะ Watchlist
1. กด “ส่งออก Watchlist สำหรับ LINE” แล้วคัดลอกเนื้อหา `watchlist.json`
2. ตั้ง Repository Secrets `WATCHLIST_JSON` เป็น JSON ที่ส่งออก เช่น `["Thai:PTT","US:NVDA","Crypto:BTC"]`
3. ตั้ง `LINE_CHANNEL_ACCESS_TOKEN` เป็น token ของ LINE OA และเปิด workflow **Watchlist new-signal LINE alerts**
4. รอบไทย 18:00 น. จันทร์–ศุกร์; รอบสหรัฐ 08:30 น. อังคาร–เสาร์ (เวลาไทย) คริปโทตรวจทั้งสองรอบ

แจ้งเฉพาะประเภทสัญญาณที่เพิ่งเกิดเมื่อเทียบกับรอบก่อน และไม่ส่งซ้ำแท่งวันเดิม เก็บสถานะใน Actions cache หลัง LINE รับข้อความสำเร็จ หาก cache ถูกลบหรือหมดอายุ อาจแจ้งซ้ำได้ เมื่อมี `WATCHLIST_JSON` รายงานตลาดทั่วไปใน workflow เดิมจะไม่ส่ง LINE เพื่อหลีกเลี่ยงแจ้งซ้อนกัน Watchlist บนเว็บไม่ซิงก์กับ Secrets อัตโนมัติ ต้องส่งออกใหม่เมื่อเปลี่ยนรายการ ระบบนี้ส่งแบบ broadcast ให้ผู้ติดตาม LINE OA

เปิด https://benzsutthi.github.io/stock-crypto-scanner/ เพื่อดู Dashboard ซึ่งแสดงหุ้นไทย หุ้นสหรัฐ และ Crypto Top 100 พร้อมค้นหา กรองสัญญาณ และจัดอันดับตามคะแนน หน้าเว็บโหลด snapshot ที่คำนวณบน GitHub Actions แล้ว ต้องเชื่อมต่ออินเทอร์เน็ต

เงื่อนไขสัญญาณประกอบด้วย 20D Breakout (ปิดเหนือ High 20 วันก่อนหน้า), RSI momentum 55–70, RSI สูงกว่า 70 (แสดงเป็นคำเตือน), RSI ต่ำกว่า 30, Volume Spike มากกว่า 1.5 เท่าค่าเฉลี่ย 20 วัน, MACD Golden Cross และแนวโน้ม EMA20/50

ข้อมูลหุ้นไทยและสหรัฐมาจาก snapshot ที่สร้างด้วย yfinance ทุก 30 นาที ช่วงตลาดเปิดดึงราคาอ้างอิงแท่ง 15 นาที นอกเวลาตลาดคงราคาล่าสุดที่มีหรือราคาปิดรายวัน สัญญาณใช้ราคาปิดปรับสิทธิ ข้อมูลไม่ใช่ real-time; ราคาคริปโทและ % เปลี่ยนแปลง 24 ชม. เป็นค่าจากผู้ให้บริการตอนสร้าง snapshot ส่วนสัญญาณทุกตลาดใช้เฉพาะแท่งปิดรายวัน

ตัวสแกน Python ใช้ yfinance/Binance วิเคราะห์และแจ้งเตือน LINE ได้กับหุ้นและคริปโทตามรายชื่อใน `config.py` โดยตั้งจำนวนเหรียญคริปโทสูงสุดไว้ 100 รายการ

## ⏰ วิธีตั้งเวลาให้รันอัตโนมัติทุกวัน (Windows Task Scheduler)

1. กดปุ่ม `Windows + S` ค้นหา **Task Scheduler** แล้วเปิดขึ้นมา
2. คลิกที่เมนูด้านขวา **Create Basic Task...**
3. ตั้งชื่อ Task เช่น `Daily Stock Crypto Scanner` แล้วกด Next
4. เลือกความถี่เป็น **Daily** (ทุกวัน) แล้วตั้งเวลาที่ต้องการ (เช่น 08:30 น. ก่อนตลาดเปิด หรือ 18:00 น. หลังตลาดปิด)
5. ในขั้นตอน Action เลือก **Start a program**
   - ช่อง **Program/script**: เลือกไปที่ไฟล์ `run_scanner.bat` 
   - เช่น `C:\Users\User_Win10x64\Desktop\skill\stock-crypto-scanner\run_scanner.bat`
   - ช่อง **Start in (optional)**: ใส่โฟลเดอร์ `C:\Users\User_Win10x64\Desktop\skill\stock-crypto-scanner`
6. กด Finish ระบบจะรันและส่ง LINE ให้คุณอัตโนมัติทุกวัน

## ⚙️ การเพิ่ม/ลด รายชื่อหุ้นและคริปโต
เปิดไฟล์ `config.py` เพื่อเพิ่มหรือแก้ไขชื่อหุ้นได้ตามต้องการ:
- **หุ้นไทย**: ต้องลงท้ายด้วย `.BK` เช่น `"CPALL.BK"`, `"PTT.BK"`
- **หุ้นสหรัฐฯ**: ใส่ตัวย่อ Ticker เช่น `"NVDA"`, `"TSLA"`, `"AAPL"`
- **คริปโต**: ใส่คู่เหรียญ USD เช่น `"BTC-USD"`, `"ETH-USD"`, `"SOL-USD"`

## ค้นหาต้นรอบและปรับปรุงข้อมูล
- เลือก Preset **ต้นรอบรายวัน · ไม่ไล่ราคา**: ฐาน 20 วันกว้าง ≤15%, เพิ่งตัดขึ้น EMA20 ภายใน 5 แท่ง / MACD ภายใน 3 แท่ง / Breakout ใหม่, EMA20 และ MACD histogram ดีขึ้น, RSI 45–65, Volume ≥1.2×, ราคาเหนือ EMA20 ≤5% และห่าง High20 −5 ถึง +3%
- คะแนนต้นรอบแยกจากคะแนนเดิม เป็นเงื่อนไขศึกษาต่อ ไม่ใช่คำแนะนำซื้อหรือการยืนยันผลตอบแทน ยังไม่ได้ backtest
- ไม่รับ snapshot เกิน 3 ชั่วโมง, ข้อมูลสำรอง หรือแท่งปิดล่าช้าเข้าตัวกรองต้นรอบ คริปโทต้องมีแท่งเมื่อวาน UTC; หุ้นเทียบวันทำการล่าสุดตามเขตเวลาตลาด ยังไม่รวมปฏิทินวันหยุดตลาด จึงอาจตัดรายการในวันหยุด
- สร้าง snapshot **ทุก 30 นาที** รวมรอบหลังตลาดปิด เว็บโหลดใหม่ทุก 5 นาทีขณะเปิดดู; GitHub Actions อาจล่าช้า ไม่ใช่ข้อมูลเรียลไทม์
- สัญญาณหุ้นใช้ **ราคาปิดปรับสิทธิ** (`auto_adjust=True`) ส่วนราคาหน้าตารางอ้างอิงแท่ง 15 นาทีช่วงตลาดเปิดเมื่อมีข้อมูล จึงอาจต่างจากราคาดิบในแอปโบรกเกอร์
- ตรวจตัวเลข, OHLC, ปริมาณ, วันซ้ำและลำดับวันก่อนวิเคราะห์ หุ้นที่ขาด/ล่าช้าลองดึงแยกรายตัว หากดึงไม่ได้เก็บข้อมูลเผยแพร่รอบก่อนพร้อมป้ายเตือน
- คริปโทจับคู่ประวัติเฉพาะ provider ID ใน `HISTORY_IDENTITIES` ไม่เดาจากชื่อย่อ เหรียญที่ยังไม่ยืนยันยังแสดงราคาแต่ไม่มีสัญญาณ เพิ่มการจับคู่ได้หลังตรวจตัวตนและคู่ตลาดจริง
- เก็บ `quoteUpdatedAt` จากผู้ให้บริการและแสดง `techPrice` แยกจากราคาปัจจุบัน ประวัติสำรอง Binance ใช้ USDT ไม่ใช่ USD
